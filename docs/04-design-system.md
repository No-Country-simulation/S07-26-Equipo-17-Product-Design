
# 🎨 Design System

## Marca

La interfaz sigue la identidad visual de **PhysaFlow**, combinando una paleta de colores **Forest Green** y **Gold** con un lenguaje visual limpio, técnico y profesional.

El sistema de diseño busca mantener la consistencia visual en toda la experiencia: calculadora, resultados, visualización de capas, comparación de escenarios y opciones para compartir.
