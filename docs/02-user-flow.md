
## 🔄 Arquitectura de la Experiencia

| Momento | Descripción |
| :--- | :--- |
| **Momento 1 — Entrada de datos** | Tres inputs: **MW, utilización y tipo de cooling**, con validación. Si los datos ingresados no son correctos, se muestra un estado de error y el usuario debe corregirlos antes de avanzar. |
| **Momento 2 — Resultado inmediato** | Entrega el valor central de la calculadora: **dinero perdido y capacidad varada**, sin fricción y antes de solicitar cualquier información al usuario. Un botón permite generar el reporte detallado. |
| **Momento 3 — Captura de email** | Se solicita el correo electrónico para acceder al análisis ampliado, con validación del email. El reporte generado tiene una **caducidad de 24 horas**. |
| **Resultado — Dashboard** | Muestra la información desglosada por capas (**Facility → IT → Workload**) e incorpora opciones para **descargar y compartir** el resultado, cerrando así el loop de crecimiento. |
