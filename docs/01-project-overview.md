# PhysaFlow Capacity Calculator

## Overview

PhysaFlow needs a calculator that allows data center operators to estimate stranded capacity and its annual financial impact in less than 3 minutes.

## Problem

Data center operators need a fast and simple way to understand how much capacity is being wasted and what that waste represents financially.

## Goal

Create a fast, understandable, and shareable calculator that provides an immediate result and allows users to explore deeper insights.

## Target User

Data center operators and technical decision makers.

## Core User Journey

Input → Basic Result → Email → Full Result → Compare → Share

## Success Criteria

- User can complete the calculator in under 3 minutes.
- Basic result is available without email.
- User understands stranded capacity in MW and %.
- User understands estimated annual financial impact.
- User can explore the Facility → IT → Workload breakdown.
- User can compare scenarios.
- User can share the result with another operator.
